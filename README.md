# Сечения многогранников — интерактивный 3D-тренажёр

Интерактивный веб-тренажёр по стереометрии для построения сечений многогранников:
- **Режим «Собери сам»**: пошаговые задачи и генератор случайных заданий (3 точки, 2 точки + параллельная прямая, 1 точка + параллельная плоскость), проверка ходов, подсказки и распил тела по плоскости сечения.
- **Режим «Конструктор»**: свободная 3D-лаборатория для разбора домашних заданий и произвольных точек на разных многогранниках.
- **Настройки сцены**: выбор цветовой схемы линий, точек, плоскости и заливки сечения, горячие клавиши в русской и английской раскладках.

Сайт полностью автономный: всё (шрифты, стили, 3D-графика и логика) собрано в один файл `index.html` без внешних зависимостей.

## Как опубликовать на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub (например, `stereometry`).
2. Загрузите **все файлы из этой папки** (`index.html`, `.nojekyll`, `.gitignore`, `README.md`) в корень ветки `main` (через **Add file → Upload files** или через `git push`).
3. Откройте **Settings → Pages** в репозитории:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `/ (root)`
   - Нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
